# Topas BI – chat-app

Statisk side (GitHub Pages) for Topas BI-agenten. Login via Supabase Auth (engangskode/link på e-mail); adgang kræver aktiv række i `bi_brugere`. Svar kommer fra Edge Function `bi-chat`.

Kilde: `supabase/functions/bi-app/app.html` i projektets mappe; denne gren genereres derfra – ret ikke her.
